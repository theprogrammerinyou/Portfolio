Movie Info is a compact entertainment discovery experience for browsing current releases or searching directly for a favourite film or series. Open a title to move from the high-level poster and rating into the details that help someone decide what to watch: cast, synopsis, related videos, and trailers.

I built it with Next.js and React, using Redux Toolkit to keep catalogue, search, and detail state predictable across the app. A REST movie API provides the live data, while a small SASS design system keeps the interface visually consistent from a dense result grid to the individual title pages. It is deployed on Netlify for a lightweight, always-available demo.
