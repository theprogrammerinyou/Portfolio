A personal VS Code extension built around the Git commands I reach for most often. It turns the repetitive add + commit + push loop into a focused one-click action, makes revert less intimidating, and exposes branch merging from the activity bar rather than forcing a context switch to the terminal.

The extension checks the assumptions that matter — Git needs to be installed and the current workspace needs to be a repository — before dispatching commands. The next step is Marketplace publishing after polishing error states and authentication prompts, so the friendly surface is backed by equally clear recovery paths.
