ShivanshUI is a drop-in CSS component set for getting a clean interface in place quickly. It includes the essentials — Alerts, Avatars, Badges, Buttons, Cards, Images, Inputs, Text, Lists, and a Navbar — with simple class-based usage and visual consistency built in.

The library was an exercise in thinking like a design-system maintainer: define sensible defaults, make states predictable, and keep the API small enough that someone can understand it in minutes. Include the base stylesheet, then pull in only the component CSS needed for a page:

`https://shivansh-ui.netlify.app/css/base.css`

`https://shivansh-ui.netlify.app/components/{name}/{name}.css`
